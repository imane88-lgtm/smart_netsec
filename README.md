# smart_netsec

Projet de cybersécurité réseau réalisé dans le cadre d'un stage.

## Description

Application de supervision et d'analyse de sécurité réseau développée avec Python.

## Fonctionnalités

- Scan réseau
- Détection des ports ouverts
- Analyse des risques
- Génération d'alertes
- Tableau de bord

## Technologies

Python, Flask, SQLite.

## Installation

Installer les dépendances et lancer l'application.
