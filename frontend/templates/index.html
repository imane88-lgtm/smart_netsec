Firewall nftables — Guide opérateur
BLOCKBouton Bloquer IP → saisir IP + raison
UNBLOCKOnglet IPs Bloquées → icône cadenas ouvert
RÈGLEBouton Ajouter règle → formulaire nftables
AUTOBouton Réponse Auto → bloque CRITICAL + HIGH automatiquement
Onglet Whitelist → IPs jamais bloquées
Onglet Blacklist → IPs malveillantes connues
Onglet Connexions Live → sessions actives (/proc/net)
Snort 3 IDS — Guide opérateur
Bouton Start → démarre Snort sur eth0
Bouton Stop → arrête Snort IDS
Bouton Auto-Block → bloque toutes les IPs CRITICAL + HIGH non traitées
Bouton Actualiser → recharge les alertes depuis la DB
Bouton Démo → injecte 10 alertes de démonstration
Bouton Reload Règles → lit /etc/snort/rules/local.rules
Filtres → Niveau + Protocole + Recherche texte libre
MITRE ATT&CK — Framework
9 phases représentées
Recon → Resource Dev → Initial Access → Execution → Persistence → Privilege Esc → Defense Evasion → Lateral Move → Exfiltration
Phases actives (rouge)
Initial Access, Execution, Defense Evasion — corrélées aux alertes Snort
Niveaux d'alerte SOC
CRITICAL P1 — Blocage nftables automatique immédiat
HIGH P2 — Blocage + alerte dashboard analyste
MEDIUM P3 — Surveillance continue + log
LOW P4 — Log uniquement
